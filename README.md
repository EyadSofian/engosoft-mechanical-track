# المسار الاحترافي للهندسة الميكانيكية — Landing Page

صفحة هبوط ثابتة (Static, Arabic RTL) لمسار الهندسة الميكانيكية من إنجوسوفت.

## البنية

| الملف | الوصف |
| --- | --- |
| `index.html` | الصفحة كاملة (HTML + CSS + JS في ملف واحد، بدون أي build step) |
| `api/leads.js` | Serverless function تستقبل بيانات النموذج وتمرّرها إلى الـ webhook |
| `assets/engosoft-logo.png` | شعار إنجوسوفت الرسمي — **لا يُعدّل ولا يُعاد تلوينه**، ويوضع دائمًا على لوحة بيضاء فوق الخلفيات الداكنة |
| `assets/plantroom-hero.webp` | صورة الهيدر الكبيرة: غرفة مضخات ومبادلات حرارية حقيقية (١٩٢٠×١٠٨٠) |
| `assets/mechanical-hero-v3.webp` | نموذج ثلاثي الأبعاد لأنظمة MEP — يُستخدم الآن كخامة خافتة خلف لوحة نموذج التسجيل |
| `assets/mechanical-course-official.webp` | صورة المسار الرسمية من موقع إنجوسوفت |

صورة الهيدر من [Pexels](https://www.pexels.com/photo/industrial-hvac-system-in-modern-facility-37604386/) برخصة Pexels المجانية (استخدام تجاري، دون إلزام بالإسناد).

## أقسام الصفحة

1. **الهيرو** — صورة غرفة المضخات بعرض الشاشة كاملًا مع تدرّج كحلي، والعنوان والنص فوقها، وشريط زجاجي ملاصق لأسفل الصورة يعرض دورات الباقة الست.
2. **لماذا تختار هذا المسار؟** — الدورات الست + البرامج + الفئة المستهدفة.
3. **لماذا إنجوسوفت؟** — أربعة أسباب + عدد المتدربين + صورة المسار الرسمية.
4. **نموذج التسجيل** — الاسم، الجوال، الدولة، المسمى الوظيفي، الموافقة على التواصل.

## مصدر المحتوى

كل رقم ومعلومة على الصفحة مأخوذة من صفحة الباقة الرسمية أو من الصفحة الرئيسية لإنجوسوفت:

| المعلومة | القيمة | المصدر |
| --- | --- | --- |
| عدد الدورات | ٦ | قسم «محتويات الباقة» |
| الدورات | HVAC · Firefighting · Plumbing · Shop Drawing · Mechanical Site · Medical Gas | قسم «محتويات الباقة» |
| المستوى | من المبتدئ إلى المتقدم | `educationalLevel` في الـ JSON-LD |
| نظام الدراسة | مسجّلة أو حضورية | مفتاح Recorded / Attendee + الأسئلة الشائعة |
| البرامج | AutoCAD · HAP · ETAB | نصوص وصف الدورات |
| الشهادة | شهادة إتمام بعد اجتياز الدورة | نموذج التسجيل على الموقع |
| المتدربون | أكثر من ٥٠٬٠٠٠ | الأسئلة الشائعة في الصفحة الرئيسية |
| أسباب «لماذا إنجوسوفت» | النصوص الرسمية الثلاثة | قسم «لأن وقتك وطاقاتك لا تُقدّر بثمن» |

**لا تُعرض أسعار على الصفحة** — السعر يُوضَّح للمهتم عبر مستشار التدريب بعد إرسال النموذج.

الصفحة الرسمية لا تذكر عدد ساعات للباقة ولا أسماء مدربين، فلم يُذكر أي منهما هنا.

## الهوية البصرية

مأخوذة من `engosoft.com` مباشرة:

- اللون الأساسي: `#155197` — والثانوي: `#0655D6`
- الخط: `Noto Kufi Arabic`
- جسم الصفحة فاتح، نصوص `#0B2237`

الطرف الداكن من الهوية — الهيرو ولوحة التسجيل والفوتر — مبني على `#071B2E` و`#0D2C48`.
اللون البرتقالي `#F08A1D` مأخوذ من شارة «الأكثر مبيعًا» في صورة المسار الرسمية، ويحمل **أزرار الإجراء وحدها**؛ الأزرق يبقى لون الهوية والبنية.

## متغيرات البيئة على Vercel

- `LEADS_WEBHOOK_URL` — **مطلوب**: وجهة استقبال بيانات المسجّلين.
- `LEADS_WEBHOOK_TOKEN` — اختياري: Bearer token يُرسل مع الطلب.

النموذج لا يُظهر رسالة نجاح وهمية أبدًا. إذا لم يكن الـ webhook مضبوطًا أو رفض الطلب، تظهر للمستخدم رسالة خطأ صريحة مع زر تواصل عبر واتساب كبديل.

## التشغيل محليًا

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173`. مسار `/api/leads` يعمل على Vercel فقط، ومحليًا سيظهر مسار واتساب البديل.
